# CLAUDE.md

## Project skills

- `mega-review` (`.claude/skills/mega-review/SKILL.md`) — exhaustive multi-agent pull-request review
  tuned to this Rails monolith. Use it when asked to "mega-review" a PR or to review one across all
  dimensions; for a quick single-pass look use `/code-review` instead.

## Project docs

- `tech_audit.md` — the shape of the stack. Where it and the code disagree, the code wins.
- `redesign_plan.md` — decisions and their history. A later section beats an earlier one; the pointer at
  the top of the file names what is superseded.
